Description (Detailed - formatted for Chrome Web Store)



🎯 Learn to solve LeetCode problems with an AI mentor that guides you to the solution, rather than giving it away.

LeetWhisper is your intelligent coding companion for LeetCode, providing progressive hints and personalized guidance that adapts to your learning pace. Unlike traditional solution lookups, LeetWhisper helps you develop problem-solving skills through thoughtful mentorship.

✨ KEY FEATURES

🧠 Adaptive Hint System
• Choose between Conceptual (approach & algorithms) or Implementation (code structure) guidance
• Progressive hints that become more specific as needed - never reveals too much too soon
• Maintains conversation context to avoid repetition

💬 Interactive AI Mentor
• Natural chat interface for asking questions
• Remembers your conversation history within each problem
• Supports both OpenAI GPT-4.1 Mini and Google Gemini 2.5 Flash

🔍 Smart Code Review
• Get instant feedback on your solution attempt
• Identifies bugs, edge cases, and optimization opportunities
• Provides actionable next steps, not complete solutions

📊 Problem Analysis
• Automatic categorization (Array, Tree, Graph, etc.)
• Identifies key concepts and patterns
• Highlights important edge cases to consider

🎨 Clean, Non-Intrusive Design
• Floating panel that doesn't interfere with LeetCode's interface
• Toggle on/off with a single click
• Position panel on left or right side
• Modern, responsive UI with smooth animations

HOW IT WORKS

1. Navigate to any LeetCode problem
2. Click the AI Assistant toggle button
3. Ask questions or request hints
4. Get progressive guidance tailored to your needs
5. Review your code for feedback
6. Learn patterns, not just solutions

PERFECT FOR

• Students learning data structures and algorithms
• Interview preparation with guided practice
• Developers wanting to understand "why" not just "what"
• Anyone stuck on a problem but wanting to solve it themselves

CONFIGURATION

• Supports OpenAI and Google Gemini API keys
• Adjustable hint detail level (Conceptual vs Implementation)
• Customizable panel position
• Automatic problem detection

PRIVACY & SECURITY

• Your API key is stored locally and never shared
• No data collection or tracking
• Open source and transparent
• Works entirely in your browser

REQUIREMENTS

• An API key from OpenAI or Google Gemini (instructions included)
• Chrome browser
• Active internet connection

💡 WHY LEETWHISPER?

Traditional solutions show you the answer. LeetWhisper helps you discover it yourself. Each hint is carefully crafted to push your thinking forward without spoiling the learning experience. It's like having a patient tutor who knows exactly how much help to give.

Whether you're preparing for technical interviews, learning algorithms, or improving your problem-solving skills, LeetWhisper transforms LeetCode practice into personalized learning sessions.

Stop memorizing solutions. Start understanding patterns.
